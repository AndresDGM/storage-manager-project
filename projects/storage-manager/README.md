# StorageManager

Librería en Angular para la gestión tipada, modular y consistente de **LocalStorage** y **Cache Storage** en aplicaciones web.

Este proyecto fue generado con [Angular CLI](https://github.com/angular/angular-cli) versión 22.2.0.

## Compilación

Para compilar la librería, ejecuta desde la raíz del espacio de trabajo:

```bash
ng build storage-manager
```

Este comando compilará el proyecto y ubicará los artefactos de distribución en el directorio `dist/storage-manager`.

## Publicación de la librería en NPM

Una vez compilado el proyecto, puedes publicar la librería siguiendo estos pasos:

1. Navega al directorio de distribución:

   ```bash
   cd dist/storage-manager
   ```

2. Ejecuta el comando `npm publish` para publicar el paquete en el registro de NPM:

   ```bash
   npm publish
   ```

## Ejecución de pruebas unitarias

Para ejecutar las pruebas unitarias con el corredor de pruebas [Vitest](https://vitest.dev/), utiliza el siguiente comando:

```bash
ng test storage-manager
```
